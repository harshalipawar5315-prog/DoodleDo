# ✨ DoodleDo 

A modern To-Do Planner web app designed with a mobile-app-like UI.

##  Live Demo
[Click here to view](https://doodle-do-beta.vercel.app/)

## 📱 Features
- Add tasks with priority (High / Medium / Low)
- Reminder system with snooze option
- Calendar view with task dots
- Custom date picker
- Multiple themes (Night, Sunset, Ocean, Purple)
- Swipe to delete tasks
- Search and filter tasks
- Sound notifications
- Data persists with localStorage

## 🛠️ Tech Stack
- HTML
- CSS (Glassmorphism + Gradient Themes)
- JavaScript (Vanilla)
- LocalStorage
